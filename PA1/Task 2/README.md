# Task 2 Results

This directory contains all machine-readable results from Task 2 experiments.

## File Listing

| File | Contents |
|---|---|
| `source_only_source_val.json` | Source-val accuracy & macro-F1 per domain + mean (source-only ERM) |
| `dan_source_val.json` | Same, for DAN |
| `dann_source_val.json` | Same, for DANN |
| `cdan_source_val.json` | Same, for CDAN |
| `source_only_curves.json` | Per-epoch cls_loss + mean source-val F1 |
| `dan_curves.json` | Per-epoch cls_loss, mmd_loss, total_loss + val F1 |
| `dann_curves.json` | Per-epoch cls_loss, domain_loss, total_loss, alpha + val F1 |
| `cdan_curves.json` | Per-epoch cls_loss, domain_loss, total_loss, alpha + val F1 |
| `*_curves.png` | Training loss curve + source-val F1 curve per method |
| `final_evaluation.json` | Full comparison: all methods × all metrics (generated by evaluate_final.py) |
| `target_accuracy_comparison.png` | Bar chart: target accuracy & F1 per method |
| `domain_separability_vs_target.png` | Dual-axis: domain separability vs target accuracy |
| `per_class_deltas.png` | Per-class accuracy delta vs source-only |
| `controlled_study_dan_lambda.png` | DAN λ_MMD sweep results (Step 6) |
| `dan_lambda_mmd*.json` | Controlled study results for each λ_MMD value |

## Reproducing Results

```bash
# Step 1 — Source-only ERM
python train.py --method source_only

# Step 2 — DAN
python train.py --method dan

# Step 3 — DANN
python train.py --method dann

# Step 4 — CDAN
python train.py --method cdan

# Step 5 — Final evaluation (uses Sketch labels for the FIRST time)
python evaluate_final.py

# Step 6 — Controlled design study (DAN, vary lambda_mmd)
python train.py --method dan --study lambda_mmd
```

## Notes

* All checkpoints are selected by mean source-validation macro-F1 (seed 6304).
* Target (Sketch) labels are consumed ONLY in `evaluate_final.py`.
* Dataset splits are saved to `shared/splits/pacs_sketch_seed6304.json` and shared with Task 3.

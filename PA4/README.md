## Common conventions
* Seed 6304. Every run records package versions, GPU, git commit, model revision and config hash
  (`<task>/results/env/`).
* Data come from the course repository in [`atml-pa4-datasets/`](atml-pa4-datasets/README.md):
  `python scripts/setup_data.py --public` materialises the fixed public selections and writes
  `data/local_source_revisions.json`, which pins every Hugging Face dataset/model commit. That lock file is committed so
  all later runs use the same commits; the materialised `data/public_locked/` files are regenerated, not committed
  (each task copies the token windows it uses into its own `results/data_selection/`).
* All reported numbers come from JSON/NPZ files under `<task>/results/`; tables and figures are regenerated by each
  task's `compile_*_report.py`.
* Hardware: Kaggle notebooks (2 × T4 16 GB, 12 h sessions), PyTorch from the Kaggle image,
  `transformers==4.57.1`, `huggingface_hub==0.36.2`.

# Data reproducibility policy

The repository includes the fixed public-dataset **row indices**, frozen MQAR splits, a deterministic MQAR training generator, and 180 frozen KV retrieval cases.

Run `python scripts/setup_data.py --public` to retrieve the actual fixed public rows and tokenized windows. The script resolves and records all source commit hashes on first run in `data/local_source_revisions.json` and reuses the same revisions on future runs. Share this lock file alongside reported experiments.

**Important:** This is a *self-service data preparation* design, not a course-wide materialized snapshot. Students who run it for the first time on different dates may resolve different Hugging Face commits. Stochastic teacher/draft prefix sequences can also differ across hardware or software even when seeded. If exact uniformity across all student submissions is needed, course staff must materialize once and publish the resulting datasets and prefix banks. Otherwise, all controlled comparisons made within a submission should use that submission's same locally prepared files and prefix banks.

No reference implementation of the student methods is included. Student-written exact speculative decoding should generate its own speculative-prefix consistency bank, and each trained student's on-policy prefix bank is necessarily generated by its own model.

The Task 2C `evidence_char_start` and `evidence_char_end` values are reserved for evaluation and diagnostics and must not be given to KV-selection algorithms. MQAR test and development files are frozen; training examples can be generated from split-specific seeds. Validate actual Qwen context lengths before interpreting length-dependent results.

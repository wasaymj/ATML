## Common conventions
* Seed 6304 everywhere; every run writes a manifest (config, package versions, GPU, git commit, model revision).
* All reported numbers come from JSON files under `<task>/results/`; tables and figures are regenerated by each task's
  `compile_*_report.py`.
* Hardware: Kaggle notebooks (2 × T4 16 GB, 12 h sessions). Large artifacts (checkpoints, merged models, the 40k
  training jsonl, token caches) are not committed (`.gitignore`).
